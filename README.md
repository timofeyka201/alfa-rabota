# Альфа-Работа — кликабельный прототип

Прототип нового сервиса **«Альфа-Работа»**, встроенного в мобильное приложение Альфа-Банка.
Открывается в браузере, работает без сборки и бэкенда.

**Слоган:** работа рядом — там же, где ваша зарплата.

---

## Что показывает прототип

### Приложение банка
Пять вкладок — Главный, Платежи, Выгода, История, Чаты — воспроизводят интерфейс
Альфа-Мобайла по референсным скриншотам: цвета сняты пипеткой с оригинала
(`#EF3124` красный, `#90DF22` пилюля «К деньгам», `#F2F3F5` фон), отступы и высоты
статус-бара, карточек счетов и таббара выставлены по замерам исходников.

Точки входа в сервис:
- **баннер нового продукта** на главной, сразу под чипами;
- **иконка «Работа»** с меткой NEW первой в строке сервисов (страховки, тревел, заправки, афиша, связь);
- строка сервисов на вкладке «Выгода» и раздел «Зарплата и доходы» в «Платежах».

### Сервис «Альфа-Работа»
| Экран | Что внутри |
|---|---|
| Лента вакансий | Вкладки **Все / В Альфа-Банке / У партнёров**, поиск, фильтры, карточки «Отклики» и «Резюме». Шапка прокручивается вместе с лентой, ей на замену выезжает компактная |
| Фильтры | Направление, опыт, уровень, формат, график, занятость, доход от, переключатели |
| Карточка вакансии | Компания с рейтингом, статистика просмотров, обязанности, требования, похожие вакансии |
| Карточка работодателя | Открывается по клику на компанию: описание, сфера, размер, география, зарплатная вилка и все его вакансии |
| Резюме | Ссылка с сайта по поиску работы или файл (**загрузка файла — заглушка**) |
| VCV-скрининг | 4 вопроса теста → 3 видеоответа → оценка 0–100 по трём критериям |
| Отклики | Статусы: отправлен, просмотрен, приглашение, отказ |
| Чат с работодателем | Ответы HR приходят по сценарию, есть быстрые ответы и разбор смысла сообщения |
| Условия для работодателей | Тарифы, требования, шаги подключения, калькулятор экономии, FAQ, кнопка «Подключить» (заглушка) |

### VCV — первичный скрининг
Заменяет первый этап отбора: кандидат отвечает на ситуационные вопросы и записывает
видеоответы **на камеру устройства**. Если доступа к камере нет — прототип автоматически
переходит в демо-режим, сценарий не прерывается.

Оценка считается арифметически: тест 40%, полнота видеоответов 25%, соответствие
профилю вакансии 35%. **Никакие модели не используются** — это имитация под демонстрацию.

### Бизнес-модель (страница условий)
Размещение почти бесплатно, доход банка — не с вакансий, а с зарплатных проектов:

| Тариф | Цена | Условие |
|---|---|---|
| Старт | 0 ₽ | зарплатный проект в Альфа-Банке (от 5 сотрудников) |
| Партнёр | 0 ₽ | зарплатный проект + РКО |
| Без зарплатного проекта | 4 900 ₽ / вакансия в месяц | для компаний без счетов в банке |

Дополнительное требование ко всем тарифам — отвечать на отклик в течение 3 рабочих дней
и указывать реальную зарплату.

## Данные

Вакансии партнёров тянутся из **открытого API «Работа России»**
(`https://opendata.trudvsem.ru/api/v1/vacancies`) — реальные вакансии по Москве,
Санкт-Петербургу, Московской области, Екатеринбургу и Казани.

Схема загрузки двухступенчатая:
1. мгновенно рисуется сохранённый срез `app/data/trudvsem-snapshot.json` (173 вакансии, 112 компаний);
2. фоном уходит живой запрос и, если он отвечает, лента обновляется.

Так демонстрация не сорвётся, даже если во время показа не будет интернета.
Источник данных подписан внизу ленты.

Профили работодателей: для Альфа-Банка и компаний Alfa Group описания написаны
под демонстрацию, для работодателей из API — собираются из их же вакансий
(число позиций, города, зарплатная вилка). Фактов о реальных компаниях не выдумываем.

Вакансии Альфа-Банка (14 штук) и компаний Alfa Group — X5 Group, АльфаСтрахование,
Альфа-Лизинг, Альфа-Капитал, Росводоканал, IDS Borjomi — написаны вручную под демонстрацию.

Пересобрать срез: `node tools-fetch.mjs`

## Запуск

Статические файлы, сборка не нужна — достаточно любого http-сервера:

```bash
npx serve app
```

Открыть `http://localhost:3000`.

### Деплой на Vercel
Импортировать репозиторий → Framework Preset: **Other** → Deploy.

Root Directory менять **не нужно**: `vercel.json` в корне уже указывает отдавать
папку `app`, сборка не требуется.

## Структура

```
app/
  index.html              оболочка: корпус телефона и пояснение для презентации
  css/
    tokens.css            дизайн-токены, цвета сняты со скриншотов
    bank.css              экраны приложения банка
    rabota.css            экраны сервиса
  gallery.html            все иллюстрации на одной странице
  js/
    app.js                точка входа
    art.js                68 объёмных иллюстраций, нарисованы вручную
    router.js             стековый роутер с сохранением прокрутки
    store.js              состояние в localStorage
    data.js               вакансии, API «Работа России», фильтры
    util.js               форматирование, иконки, общие блоки
    screens/
      bank.js             главный, платежи, выгода, история, чаты, профиль
      rabota.js           лента, фильтры, вакансия, условия работодателям
      apply.js            резюме, отклик, VCV-скрининг
      chat.js             отклики и чат с работодателем
  data/
    trudvsem-snapshot.json
tools-fetch.mjs           разовый сбор среза вакансий
tools-gallery.mjs         сборка страницы с иллюстрациями
```

Кнопка **«Сбросить демо-данные»** слева очищает резюме, отклики и чаты.

## Графика

В прототипе нет эмодзи и сторонних наборов иконок — все 68 иллюстраций
нарисованы вручную в `app/js/art.js` в едином стиле: насыщенный градиент
корпуса, тёмная грань снизу для объёма, белый блик сверху и мягкая тень
под предметом.

Градиенты и фильтры лежат в одном скрытом `<svg>`, который вставляется в
документ один раз, поэтому в разметке иконки — это лёгкие ссылки на
`url(#…)`, а не копии описаний. Размер иллюстрация берёт от `font-size`
контейнера (`1.2em`), так что она встаёт ровно на место прежнего эмодзи.

Посмотреть весь набор: откройте `app/gallery.html`, пересобрать —
`node tools-gallery.mjs`.

## Границы прототипа

- Загрузка файла резюме — заглушка, кнопка «Добавить демо-файл» продолжает сценарий.
- Кнопка «Подключить» на странице работодателя ведёт на экран-заглушку.
- Ответы работодателя в чате имитируются таймерами и разбором ключевых слов.
- Видео никуда не отправляется и нигде не сохраняется.
- Данные счетов, кэшбэка и операций — демонстрационные.
- Экраны вне сценария сервиса показывают тост «вне рамок прототипа».
